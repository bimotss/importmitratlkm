## Kode dan status aktivasi

- Apps Script: `apps_script/MitraProgress.gs` sudah dipasang pada seluruh 25 project melalui editor browser, dan versi akhirnya terkonfirmasi Saved to Drive. Catatan baseline progress disiapkan langsung lewat Sheets; tidak perlu menjalankan setupMitra lagi. Nama project sumber NJE dibetulkan menjadi Tracking_data_NJE.
- Uji onEdit langsung pada baris kosong ADYAWINSA membuktikan Inhand, Finish Survey, tanggal HOLD, DROP, dan PLAN DROP terisi. Simulasi HOLD 3 hari + durasi sebelumnya 2 hari menghasilkan 5 hari. Data dan catatan pada baris uji 999 sudah dibersihkan, lalu diverifikasi kosong.
- Fungsi harian updateDailyAging dan pemeriksaan edit kolom tracking untuk owner dipertahankan dengan nomor kolom yang ditentukan dari header. Label grouping 1-10 dipaksa menjadi teks agar tidak dikonversi ke tanggal. Pemicu aging harian belum diverifikasi di setiap project.
- Importer lokal: 35 sumber (28 FO + 7 RADIO), termasuk NJE dengan nama tab asli data_NATA_JAYA_ELEKTRO. Rekap FO 58 kolom termasuk MITRA.
- Aging FO menggunakan Real Start Progress jika tanggal valid tersedia, bukan tanggal finish tahap yang telah dilewati.
- Validasi lokal: 113 tes Python dan 16 tes JavaScript lulus; Ruff lulus.
- Uji impor Google langsung berhenti sebelum pembacaan sumber pertama: token OAuth lokal expired/revoked (invalid_grant). Tidak ada hasil rekap yang dipublikasikan oleh percobaan tersebut.
